# Nivesh Portfolio

A clean, beginner-friendly portfolio site with HTML, CSS, and JS.

## Quick Start
1. Unzip this folder.
2. Make sure `assets/profile.jpg` exists (your photo).
3. Open `index.html` in your browser.
4. Edit text in `index.html`, styles in `style.css`, and behavior in `script.js`.

## Deploy (free options)
- GitHub Pages: push to a repo and enable Pages.
- Netlify / Vercel: drag & drop the folder.
